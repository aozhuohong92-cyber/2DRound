# 英雄面板人物（透明人物图）

来源：用户提供的「全英雄面板人物.zip」，由原包 Spine 3.4 `show` 模型渲染成透明 PNG（2026-10-17）。
共 174 个英雄，每个英雄一张 `<英雄编号>_<英雄名>.png`（600×800 透明画布，个别静态回退图尺寸不同），
内容原样保留。

| 项 | 说明 |
|---|---|
| `<编号>_<名>.png` | 面板人物原图，统一画布，保留各英雄相对大小与脚底基线 |
| `预览/` | 174 个英雄总览图，用于人工核对 |
| `manifest.csv/json` | 模型编号、来源类型、回退原因、`alpha_bbox`（人物不透明范围，可用来还原"透明裁切"版） |
| `原资源清单.json` | 每个文件的 SHA-256 |
| `来源说明.md` | 提供者的原始说明 |

## 规则与注意

- 运行时逻辑路径 `resource/heroportrait/<英雄编号>.png`（本项目自定，原游戏没有这个路径），
  构建时由 `hero_art.py` 按哈希路径打进 APK。
- 提供者另有「透明裁切」版（每个人物按边界裁切并留白），未归档：它可由原图和 `alpha_bbox` 得到。
- 例外：20511 甚平的最高星模型 `H32107` 未随包，用 `H31107`；70527 佩罗斯佩鲁的 Spine 在软件渲染器下崩溃，
  用原包静态面板图。其余均为 Spine `show` 渲染（共 173 个，静态回退 1 个）。
- 这些是**渲染得到的图**，不是原包资源本体；人物姿势取 `show` 动画的渲染帧。
- 重新归档：`python3 outputs/offline-client/organize_portraits.py <解压目录>`。
