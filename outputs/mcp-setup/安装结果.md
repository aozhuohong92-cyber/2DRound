## 使用入口

- Cocos：运行同目录“启动Cocos工作台.command”。工作台只是扩展验证工程，不是已恢复游戏。扩展随工程自动开启 localhost:3000。
- Mobile：连接 Android 真机或启动下面的模拟器，再查询设备即可。
- JADX：运行“启动JADX.command”，在 Plugins → jadx-mcp: Settings... 点击 Start，保留 127.0.0.1:8090。插件已安装且自检成功，但 GUI 内的长期服务未自动启动；桌面 MCP 未能选中 Java 窗口，因此未冒充已完成这个点击。
- Ghidra：配置为 stdio 无界面模式，会自动打开此项目的 libcocos2dlua.so，不需要手工启动 Ghidra GUI。当前使用 --no-analyze 避免每次连接全库长时间分析，仍可按地址反编译；源码质量需要人工判断。日志里的警告未消除，不代表已恢复原始源码。

新增连接在宿主重新加载 MCP 配置后才能作为本会话工具出现。当前实际测试使用独立 MCP 客户端完成；若工具列表没有更新，可重新打开任务或重启应用。
